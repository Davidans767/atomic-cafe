# Business Card — v2 (Active)

> **v1 deprecated** (2024 version had old logo + old phone number, do not reprint)

## Spec

- **Size:** 85x55mm (standard ISR)
- **Stock:** 350gsm matte recycled, slight texture
- **Finish:** Spot UV on logo only
- **Print:** Double-sided, full color
- **Quantity:** 500 (last print run: March 2025)

## Front

```
+-----------------------------+
|                             |
|     [LOGO - centered]       |
|                             |
|        Atomic Cafe          |
|     קפה · אוכל · אנשים      |
|                             |
+-----------------------------+
```

- Background: cream (#FAF3E7)
- Logo: 30mm wide, centered, ink color (#22262D)
- Tagline: Heebo 400, 9pt, ink color, letter-spacing 0.5
