# Instagram Story Template — Atomic Cafe

## Format
- 1080x1920px (9:16)
- Safe zone: 250px from top/bottom (avoid UI overlap)
- Hebrew RTL — text aligned right

## Default Layout

```
+------------------+
|   [logo - top]   |  <- Atomic Cafe logo, 80px, ink color
|                  |
|   [photo/video]  |  <- Hero visual (food/drink/vibe)
|     center       |
|                  |
|   [headline]     |  <- Heebo 900, 64pt, white on dark overlay
|   [subtitle]     |  <- Heebo 400, 28pt
|                  |
|   [CTA button]   |  <- "הזמינו עכשיו" / "בואו לבקר"
+------------------+
```

## Color Treatments

- **Morning posts** (06:00-11:00): warm cream background (#FAF3E7), dark coffee text (#3B2A1E)
- **Lunch posts** (11:00-15:00): clean white (#FFFFFF), accent green (#5B8C5A)
- **Evening posts** (17:00-22:00): deep navy (#1A2238), warm amber accent (#E8A33D)

## Variations

### Variation A — Product highlight
Photo of single drink/dish, name overlaid bottom, price tag top-right corner

### Variation B — Quote/vibe
Solid color background, big Hebrew quote, small logo bottom

### Variation C — Behind the scenes
Video (15s max), captions burned in, music sticker bottom

### Variation D — Stickers/polls
"איזה קפה היום?" poll with 2 options
"דרגו את העוגה החדשה" slider
